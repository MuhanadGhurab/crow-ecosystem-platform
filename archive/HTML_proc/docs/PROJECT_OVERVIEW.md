# Project overview — CyberCrow

## Goal

Build **CyberCrow** as a serious technology brand that connects:

- A tailored **ERP** request aligned with the company’s needs.
- Clear **ERP module** selection with English UI labels (seed data may retain `name_ar` for future localization).
- A CyberCrow **security layer** (English product names and descriptions in the default UI).
- A **subscription plan** priced in SAR, with a live monthly estimate while completing the form.

## Audience

Organizations (including Saudi and Gulf teams) that want a grounded **SaaS/ERP** request experience with readable English for technical terms, without noisy visuals.

## Current status

- **Phase 1 (done):** English / LTR shell, full request wizard, live estimate, `localStorage` persistence, client dashboard, admin preview.
- **Phase 2 (active):** backend APIs, authentication, server-side pricing and audit logs.

## Security principle

Security is not only marketing copy; it is reflected in the **request path** (explicit security layer choice) and in **request metadata** (modules, plan, status, logs on the server in Phase 2).

## Owner and technical vision

**Muhanad Ghurab** — CS/IT graduate with a security focus, working as an IT specialist, building CyberCrow as a long-term platform rather than a shallow demo.

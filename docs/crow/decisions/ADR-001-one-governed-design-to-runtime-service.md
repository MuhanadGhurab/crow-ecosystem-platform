# ADR-001: Crow Is One Governed Design-to-Runtime Service

| Field | Value |
|-------|-------|
| **Status** | Accepted |
| **Date** | 2026-07-04 |
| **Implementation status** | Product direction locked; partial implementation |

## Context

Crow was described inconsistently as ERP, module marketplace, AI org generator, or consulting deliverables.

## Decision

Crow is **one governed design-to-runtime service** producing Operating Model, Enterprise Blueprint, and Operational Tenant as connected outcomes.

## Rationale

Unifies sales, engineering, and AI agents on a single product definition. Prevents scope drift into generic SaaS configurator patterns.

## Alternatives rejected

- Separate products for Build vs Transform
- ERP-first positioning
- AI-first autonomous organization generator

## Consequences

All portals, lifecycles, and milestones derive from this single service model.

## Affected domains

All — constitution, portals, lifecycle, commercial model

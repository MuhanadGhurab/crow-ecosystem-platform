# ADR-011: The Public Scroll Story Is Frozen and Not the Final Public Direction

| Field | Value |
|-------|-------|
| **Status** | Accepted |
| **Date** | 2026-07-04 |
| **Implementation status** | FROZEN — code retained at `/experience/architects-map` |

## Context

Cinematic scroll-story experiment explored narrative public UX but is not the approved enterprise SaaS direction.

## Decision

Scroll-story status: **RESEARCH REFERENCE / FROZEN / PLANNED RETIREMENT AFTER REPLACEMENT VALIDATION**. Approved direction is professional interactive enterprise SaaS site per [`09-PUBLIC-EXPERIENCE.md`](../09-PUBLIC-EXPERIENCE.md).

## Rationale

Preserves research investment while preventing agents from extending frozen experiment as canonical UX.

## Alternatives rejected

- Immediate removal before replacement validated
- Continuing scroll-story as primary homepage direction

## Consequences

Do not remove in documentation milestones. Do not invest in scroll-story expansion. Implement approved v2 in CROW.PUBLIC.* milestones.

## Affected domains

Public Portal, Marketing

# Staging without Vercel (optional tunnel)

**Default path:** [`LOCAL_STAGING.md`](LOCAL_STAGING.md) — localhost + Supabase, Azure prod later.

Use this file only for **optional public tunnel** when Omar cannot use your screen on localhost.

```powershell
npm run staging:local    # terminal 1
npm run staging:tunnel   # terminal 2 (optional)
```

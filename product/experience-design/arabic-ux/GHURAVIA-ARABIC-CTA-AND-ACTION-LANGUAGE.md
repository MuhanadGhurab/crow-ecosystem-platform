## Button grammar

Buttons:

1. begin with a clear verb;
2. describe the result;
3. remain short;
4. do not use poetic language when action clarity matters.

### Preferred patterns

| Intent | Arabic |
|--------|--------|
| Enter product | ابدأ رحلتك |
| Enter world / portal | ادخل العالم |
| Explore horizons | استكشف الآفاق |
| Enter mission | ادخل المهمة |
| Enter district / workspace | ادخل مساحة العمل |
| Review decision | راجع قرارك |
| Show outcome | اعرض النتيجة |
| Explore alternate | استكشف مساراً بديلاً |
| Return to original | عد إلى رحلتك الأصلية |
| Choose another path | اختر مساراً آخر |
| Accept recommendation | قبول المقترح |
| Dismiss recommendation | تجاوز المقترح |
| Sign in | تسجيل الدخول |
| Skip ceremony motion | تخطَّ العرض الحركي |
| Reduce motion | تقليل الحركة |
| Open signals | عرض الإشارات |
| Close | إغلاق |
| Hide signal | إخفاء |

### Rejected patterns

| Avoid | Why |
|-------|-----|
| ادخل العالم · ادعُ جناحيك | Mixed poetic CTA; second clause unclear as action |
| أدلة أولاً (alone) | Category label, not action |
| إلى غرفة Crowprint (alone without context) | Spatial metaphor without purpose |

## Labels

- Use concise nouns for navigation and state chips.
- Do not hide actions inside labels.
- Keep the same label for the same concept across screens.

## Decision actions

State the concrete intervention, then the trade-off in a secondary line:

```text
اجمع معلومات إضافية قبل تنفيذ التغيير
قد يتأخر استعادة الخدمة، لكنك ستحصل على صورة أوضح للمشكلة.
```

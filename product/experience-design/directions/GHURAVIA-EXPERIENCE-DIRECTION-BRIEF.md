## Purpose

Develop three controlled visual/experience directions for the first recognizable GHURAVIA product journey:

1. **World Portal** (public world entry)
2. **Black Signal Mission Workspace**
3. **Crowprint / Flight Log Debrief**

## Design goals

Feel like: living digital skill world · consequential learning · Arabic-first · cinematic without confusion · advanced without generic cyber-dashboard · mature 15+ · recognizably GHURAVIA beyond Crow art alone.

Must not resemble: blog · docs site · LMS · admin panel · course marketplace · SaaS dashboard · gaming launcher · SOC clone · childish classroom · glowing card collage.

## Direction family

| Code | Name | Thesis |
|------|------|--------|
| **A** | Founder Anchor | Obsidian · cyan · restrained gold · cinematic Crow-world atmosphere |
| **B** | Refined Anchor | Same identity; stronger readability, hierarchy, a11y, reusable structure |
| **C** | Challenger | Same identity laws; more spatial/environmental; minimize dashboard/card conventions |

Each direction is one coherent family across all three anchors.

**Prototype expansion reference (not Founder selection):** Direction **B** receives additional mobile boards because it maximizes readability/feasibility for implementation planning. Founder may still select A, C, hybrid, or reject all.

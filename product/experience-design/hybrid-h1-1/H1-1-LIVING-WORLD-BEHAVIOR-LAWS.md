# H1.1 — Living-World Behavior Laws

| Field | Value |
|-------|-------|

## Interaction classes

| Class | Role | Rule |
|-------|------|------|
| **Ambient** | Life without demand | Never block reading; max 2 continuous ambient animations/viewport |
| **Informational** | State / change | Always include text equivalent |
| **Interactive** | Direct user response | Immediate; ≤300ms before usable |
| **Ceremonial** | Rare meaningful transitions | Skippable; 600–1200ms max |

## Feel targets

Modern · technologically advanced · responsive · atmospheric · alive · interactive · reactive to scroll and decisions · media-slot ready.

## Must not weaken

Arabic readability · accessibility · reduced-motion · mobile · performance · Mission clarity · Crowprint explainability · user control.

## Hard prohibitions

Constant particle storm · scroll hijacking · motion-only meaning · notification spam · Crow mascot spam · loot-box Crowprint · autoplay audio · blocking animations >300ms on primary actions.

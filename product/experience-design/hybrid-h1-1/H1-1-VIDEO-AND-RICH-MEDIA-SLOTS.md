| Field | Value |

## Slots

| Slot | Use | Fallback |
|------|-----|----------|
| Hero ambient video | Portal sky loop | CSS atmosphere + poster |
| Animated world loop | Depth layers | Gradient drift |
| Horizon environment clip | Focus state | Static silhouette |
| Mission cinematic briefing | Briefing entry | RAVEN text panel |
| Crow fly-through | Ceremonial entry | SVG silhouette |
| Crowprint reveal animation | Seal formation | CSS seal draw |
| Echo divergence viz | Branch | SVG fork |

## Runtime rules (future Product Code)

Respect `prefers-reduced-motion` · Save-Data · mobile · `document.visibilityState` · battery-conscious · mute autoplay only · captions/transcripts planned · pause off-screen · lazy-load.

Prototype may use poster placeholders and CSS/SVG only.

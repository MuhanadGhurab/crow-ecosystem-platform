# Hybrid H1 — Visual Laws

| Field | Value |
|-------|-------|
| **Status** | FOUNDER-DIRECTED HYBRID — READY FOR FINAL VISUAL REVIEW |
| **Soul** | Direction A |
| **Structure** | Direction B |
| **Spatial moments** | Direction C (selective) |

## Must feel like

Living digital skill world · Arabic-first international product · consequential learning · modern cyber-cultural · mature 15+ · cinematic yet operationally clear · uniquely GHURAVIA without depending only on Crow artwork.

## Must not resemble

Blog · docs site · LMS · admin panel · generic SaaS dashboard · SOC dashboard · course marketplace · gaming launcher · card-grid homepage · neon cyberpunk template · luxury gold-and-black landing · children’s gamification.

## Color-role model

| Role | Intent | Hard rule |
|------|--------|-----------|
| Obsidian depth | Night-world atmosphere | Base canvas |
| Cyan signal | Live change, guidance, focus ally | Max **one** meaningful soft cyan glow per view |
| Restrained gold | Ceremony only | Horizon marks · Crowprint reveal — never body copy or ordinary chrome |
| Mist / secondary | Meta, muted panels | Lower contrast than primary text |
| Muted risk crimson | Risk / debt | Never neon alarm spam |
| Success teal-green | Continuity / healthy | Paired with shape/label |

## Restraint laws

- No excessive glowing · no pill-button sprawl · no glassmorphism everywhere  
- No decorative topology · no fake live activity · no generic stats dashboard  
- No unreadable low-contrast text · no learner-facing internal IDs  
- Max **four** surface depth levels: deep · base · elevated · overlay  
- Borders preferred over heavy shadows  
- Visible focus indicator required  

## Atmosphere vs comprehension

When A’s atmosphere conflicts with B’s readability or accessibility, **B wins**. C never becomes default navigation or decision architecture. No first-person navigation. Spatial metaphor must not be required to reach essential content.

## Binding identity equation

```text
Chosen Lineage
=
user-controlled exploratory focus

Suggested Lineage
=
private, explainable, dismissible system recommendation

Earned Lineage
=
valid Evidence
+ applicable Mastery
+ capability coverage
+ freshness
+ integrity
+ governed decision
```

Mandatory separations: Chosen ≠ Suggested ≠ Earned; Wingprint ≠ Lineage; Nest readiness ≠ Lineage; Horizon choice ≠ permanent identity; Route enrollment/completion alone ≠ Lineage; Payment/Entitlement/Popularity/Trust/Prestige ≠ Lineage; Evidence Seal ≠ Lineage Mark ≠ Fusion Signature.

One state may inform a later decision; no state silently transforms into another. Every transition must be explicit, explainable and auditable.

## Summary locks

- **Chosen:** reversible exploration; no Mark; no proof.
- **Suggested:** always private; dismissible; Origin/Nest/Trust/payment prohibited as inputs.
- **Earned:** Evidence-before-Mastery; full state machine including lapse ≠ revoke.
- **Privacy:** default private; Suggested never public; minors OFF by default.
- **Symbols:** Lineage Mark only for Earned Active (policy for revalidation); Trust symbol prohibited.
- **Taxonomy evolution:** ADD/RENAME/CLARIFY/DEPRECATE/SUPERSEDE/SPLIT/MERGE effects defined.
- **Cross-Wing:** eligibility grammar only; Majors not activated; access ≠ award.
- **Evolved Roles:** DEFERRED.
- **Wingprint:** presentation only.
- **Localization:** English authoritative; Arabic CONTROLLED PROVISIONAL; native review NOT RUN.
- **Unresolved critical collisions:** **0** (handoff grammar complete for 60 pairs).

## Ratified formal noun

| Form | Status | Use |
|------|--------|-----|
| **Core Crow Lineage** | **LOCKED** formal internal English | Governance, schemas, baselines, Gate language |
| **Crow Lineage** | **LOCKED** concise user-facing English | UI copy where “Core” is unnecessary |
| **Definition** | **LOCKED** | A governed GHURAVIA role-and-specialty archetype associated with one Horizon. It is a taxonomy concept, not ancestry, birthright, rank, proof, or a permanent career classification. |

### Noun ratification rationale

| Rejected / contrasted reading | Why rejected |
|-------------------------------|--------------|
| Ancestry / bloodline / family tree | Implies inheritance; GHURAVIA identity is practiced capability archetype, not descent. |
| Race / ethnicity / species taxonomy of people | Prohibited biological/social essentialism; “Crow” is product metaphor, not demographic class. |
| Caste / hereditary station | Prohibited permanent social hierarchy. |
| Prestige (Ascendant / Apex / Obsidian) | Prestige is a separate Progression recognition class; not a Lineage. |
| Rank / military grade | Lineage is not command seniority; L2 “Mission Commander” is specialty language, not org rank. |
| Species / creature subtype | Visual species art (1D) must not redefine taxonomy meaning. |
| Proof / Evidence / Mastery award | Lineage taxonomy ≠ earned proof; Evidence precedes any earned expression (1C). |
| Nest readiness / Flight-Ready | Nest is onboarding readiness, not Lineage award. |
| Wingprint | Presentation/personalization surface, not Lineage. |

Arabic formal noun remains **CONTROLLED PROVISIONAL** pending native-Arabic validation (see localization status).

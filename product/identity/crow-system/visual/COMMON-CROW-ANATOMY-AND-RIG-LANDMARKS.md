## Species-family rule

All 25 Lineages share one GHURAVIA Crow anatomy family. Differences are **role-and-specialty visual grammar**, not biological race, caste, ancestry, or prestige hierarchy.

## Landmarks

| Landmark | Definition |
|----------|------------|
| Head / beak | Beak tip, beak hinge, crown, nape |
| Eye / brow | Eye center, brow ridge (non-aggressive default) |
| Neck / chest | Neck root, chest mass center |
| Shoulder / wing roots | L/R wing root pivots |
| Primary / secondary wing zones | Outer primaries; inner secondaries |
| Tail | Tail root, tip, flare points |
| Legs / talons | Knee, ankle, perch contact |
| Stances | Perched · Standing · Flight silhouette |
| Views | Front · side · three-quarter |
| Rig pivots | Root, chest, neck, wing roots, tail root |
| Safe accessory zones | Shoulder pads, wing-edge slots — never replace silhouette ID |
| Protected identity-mark zone | Chest clear-space for Lineage Mark when authorized |
| Wingprint overlay zones | Surface fills/patterns outside silhouette-critical edges |

## Prohibitions

- No Lineage as different biological race/caste
- No Horizon inherently stronger/smarter/wealthier/prestigious
- No disability caricature anatomy
- No predatory/villain defaults; no military rank hierarchy
- No religious/national symbols; no copyrighted character resemblance

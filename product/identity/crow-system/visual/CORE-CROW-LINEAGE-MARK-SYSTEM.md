## Grammar

```text
Horizon family geometry
+
Lineage-specific differentiator
=
Lineage Mark
```

Marks must be semantically derived, non-text-dependent, monochrome-capable, small-size recognizable, distinct, Wingprint-stable, theme-stable, and deterministically versioned.

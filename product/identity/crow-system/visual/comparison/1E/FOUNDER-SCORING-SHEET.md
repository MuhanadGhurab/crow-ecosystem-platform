# Founder Scoring Sheet

## Review order

1. Hard-gate review of solid-black silhouettes.
2. Blind `X/Y/Z` structural scoring.
3. 48 px and crop tests.
4. Cinematic review.
5. Reveal A/B/C labels and generation traceability.
6. Cursor recommendation.
7. Founder decision.

Do not reverse this order. A spectacular background cannot rescue a failed
Mother Form.

## Hard gates

A candidate is founder-ineligible if any answer is `Fail`.

| Hard gate | Pass condition |
|---|---|
| Anatomy | One head, one beak, two attached wings, two legs, two feet; no impossible intersection or floating anatomy |
| Mother Form anchors | All four locked Horizon anchors are visibly respected |
| No-color meaning | Horizon remains readable in solid black and grayscale |
| 48 px survival | Defining structural relationship survives at 48 px |
| Same species | Remains inside GHURAVIA corvid anatomy and material world |
| Namespace safety | No Evidence, Fusion, Rank, Prestige, Wingprint, Lineage Mark, or Trust cue |
| Collision safety | Does not primarily read as another Horizon |
| Rig plausibility | Neutral idle, signature posture, wing fold, and reset are physically plausible |
| Anti-generic | Identity is structural, not “raven + blue circuitry + background” |
| Scope | No child Lineage, Cross-Wing, runtime, or entitlement design leakage |

## Weighted criteria

Score each criterion from `0` to `5`, then apply the weight.

| Criterion | Weight | A score | B score | C score |
|---|---:|---:|---:|---:|
| Still looks like the chosen GHURAVIA Crow | 25% |  |  |  |
| Horizon readable without color | 20% |  |  |  |
| Can support five distinct Lineages | 15% |  |  |  |
| Works full-body, portrait, thumbnail, and silhouette | 15% |  |  |  |
| Can animate and become a coherent 3D rig | 10% |  |  |  |
| Avoids generic AI cyber-bird language | 15% |  |  |  |
| **Weighted total / 100** | **100%** |  |  |  |

### Score meaning

| Score | Meaning |
|---:|---|
| `0` | Absent or directly violates the criterion |
| `1` | Major failure |
| `2` | Weak; substantial redesign required |
| `3` | Viable direction with visible risk |
| `4` | Strong; controlled refinement remains |
| `5` | Exceptional and production-direction worthy |

Founder eligibility requires:

- every hard gate `Pass`; and
- weighted score of at least `80/100`.

Passing the threshold does not select a winner.

## Five-Lineage growth test

For each candidate, answer without drawing final children:

1. Which 80% of the silhouette is inherited by all five children?
2. Which 20% can carry five different Strength Signatures?
3. Can head, wing, tail, marking, material, and motion variation occur without
   erasing the Horizon?
4. Does any future child become impossible because the Mother Form is too
   specific?
5. Does the candidate force every child into the same personality?

Any candidate that cannot support five children receives no more than `2/5` for
Lineage growth.

## Animation and 3D test

Record:

- neutral idle;
- signature action;
- reset motion;
- wing fold path;
- center-of-mass shift;
- likely rig complexity;
- topology risks;
- silhouette at front, three-quarter, and side;
- any element that depends on impossible feather or joint behavior.

Detached modules and floating machinery are automatic failures.

## Recommendation rule

Cursor may recommend one candidate per Horizon. It must state:

- why it best preserves GHURAVIA;
- what it improves;
- what risk remains;
- what is lost relative to the other two;
- whether selecting it reopens an existing lock.

Cursor may not write the founder-selection field.

# Founder Visual North Star

## Binding intent

The existing visual work contains GHURAVIA's emotional identity. This gate
evolves that identity; it does not replace it.

> **70% preserve · 20% refine · 10% challenge**

The ratio governs the portfolio's design-change budget. It does not make A, B,
and C equally free to diverge.

## Style invariants

Every candidate remains visibly the chosen GHURAVIA Crow through:

- believable corvid anatomy and physical balance;
- obsidian-black organic plumage;
- technology integrated into feather structure rather than attached as gadgets;
- crisp feather separation without metallic costume armor;
- controlled cool rim light and restrained cyan/silver accents;
- deep near-black cinematic space with readable shadow detail;
- intelligence conveyed through posture and attention;
- premium modern realism without generic game-asset excess.

## Anti-generic test

Cover all cyan light and remove the background.

The candidate must still show:

- a specific Horizon;
- a designed relationship between head, torso, wings, and tail;
- a controlled feather topology;
- one memorable structural sentence;
- the same GHURAVIA species.

If it becomes “a black raven with cyber details,” it fails.

## Reference weighting rule

When the generation system supports reference weights:

- species/style anchor: strongest aesthetic reference;
- Horizon structural reference: strongest shape reference;
- personality evidence: low secondary influence only;
- no rejected or historical raster reference.

Record the exact weights. If weights are unsupported, state that honestly and
use the minimum reference set required to preserve the style.

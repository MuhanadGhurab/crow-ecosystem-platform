# GHV.CROW-IDENTITY.1E — Founder Visual Direction Comparison

**Prepared:** 2026-07-24  
**Status:** Execution-ready handoff; visual generation not yet run  
**Authority:** Founder-directed candidate gate  
**Runtime implementation authority:** None

## Outcome

This package prevents the GHURAVIA Crow art direction from being restarted from
zero. It remounts the strongest existing visual work as controlled references,
then instructs Cursor to produce a bounded comparison at the five Mother Form
level.

The gate creates three directions for each Horizon:

- **A — Founder Anchor:** closest to the visual identity already liked.
- **B — Refined Anchor:** the same soul with stronger silhouette, rig, and
  production consistency.
- **C — Challenger:** one controlled alternative interpretation under the same
  GHURAVIA identity laws.

The portfolio doctrine is:

> **70% preserve · 20% refine · 10% challenge**

This is a change budget, not an instruction to make one third of the system
experimental.

## Current authority order

When two artifacts disagree, use this order:

1. `GHV.CROW-IDENTITY.1D` repository baseline and its controlled reference
   plates.
2. The canonical Mother Form, Strength Signature, and identity documents in
   `references/canon/`.
3. `references/locked/ANALYZE-MOTHER-FORM-LOCK.md`, which supersedes the older
   finding that Analyze was unresolved.
4. Founder visual anchors in `references/founder-anchor/`.
5. Personality evidence in `references/personality-evidence/`.
6. Historical and rejected studies, which may be audited but may not be used as
   generation references.

## Scope

This gate may:

- mount approved-looking references beside the existing `1D` gate;
- create 15 controlled Mother Form candidates;
- validate silhouettes, thumbnails, cinematic masters, animation/3D
  plausibility, and cross-Horizon collisions;
- recommend one direction per Horizon;
- prepare a founder decision register.

This gate may not:

- regenerate the 25 Lineage Crows;
- create final Cross-Wing characters;
- change Rank, Prestige, Evidence, Trust, Wingprint, or Fusion namespaces;
- alter product runtime, UI, database, API, or deployment code;
- select GHURAVIA's final face without the founder's explicit decision;
- overwrite historical reports or the existing Analyze lock.

## Gate completion state

Cursor must finish with:

> `FOUNDER_DECISION_PENDING`

The gate becomes `PASS` only after the founder records one selected production
direction for all five Horizons. A numerical score or Cursor recommendation is
not a founder decision.

## How to use

1. Place this package inside the GHURAVIA repository workspace without changing
   its contents.
2. Open
   [`CURSOR-EXECUTION-DIRECTIVE.md`](CURSOR-EXECUTION-DIRECTIVE.md) in Cursor.
3. Give Cursor that file as the binding execution directive.
4. Cursor must locate the existing `GHV.CROW-IDENTITY.1D` gate and mount `1E`
   beside it. It must not create a second parallel Crow design system.
5. Review the blind boards and completed
   [`FOUNDER-SCORING-SHEET.md`](FOUNDER-SCORING-SHEET.md).
6. Record the founder choice in
   [`FOUNDER-DECISION-REGISTER.md`](FOUNDER-DECISION-REGISTER.md).

Locks are **visually and behaviorally distinct**. Hidden UI ≠ Authorization (Constitution).

Shared structure:

```text
┌────────────────────────────────────────────┐
│ Lock type label                            │
│ What is missing                            │
│ Why it matters                             │
│ Exact path / options                       │
│ [Primary resolve]  [Secondary]  [Cancel]   │
└────────────────────────────────────────────┘
```

---

## Learning Prerequisite

- Missing: named prerequisite Route/Stage/Mission/Evidence.
- Why: readiness for advanced work.
- Path: open Learning Graph (WLD-003) / prerequisite Route.
- Action: Start prerequisite. **No payment CTA dominance.**

## Readiness Requirement

- Gap vs Nest bands (Scope §3.5).
- Options: Nest path, Micro-Mission, retest conditions.
- Language: no shame; low result ≠ lower human value.

## Commercial Entitlement

- Missing access / capacity.
- Smallest eligible plan; current Route capacity.
- Merit alternative when available.
- **No implication of Skill purchase.**

## Merit Eligible

- Merit requirement (placeholder criteria pending).
- Required Evidence/achievement + progress.
- Optional commercial alternative (secondary).

## Trust Requirement

- Required Trust state + reason.
- How to become eligible (moderation policy, positive participation).
- No pay-to-trust.

## Assurance Requirement

- Phone / passkey / MFA / trusted identity as applicable.
- Privacy explanation.
- Primary: Improve assurance (TRU-003/004).

## Capacity Lock

- Current active Routes vs plan concurrency (Scope §3.19).
- Options: Pause Route · Upgrade plan · Merit Grant · Cancel.

## Event Lock

- Schedule, capacity, eligibility.
- Spectate option when allowed.
- Next opportunity.
- Participant vs spectator separation preserved.

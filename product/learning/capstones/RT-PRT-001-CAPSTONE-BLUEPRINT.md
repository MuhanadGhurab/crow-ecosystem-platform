## Learner tasks (blueprint — not step-by-step exploit guide)

1. Triage the seeded alert set with prioritization and FP/TP reasoning.  
2. Investigate using playbook discipline on **provided** lab artifacts only.  
3. Build an investigation timeline with sources and confidence/gaps.  
4. Recommend proportionate containment / escalation **within lab authority**.  
5. Produce incident communication brief and investigation report.  
6. Submit Evidence pack with ethics declaration; sanitize for portfolio.

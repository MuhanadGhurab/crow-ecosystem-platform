## Pilot criteria (gate §45)

Before any Route is published, representative Missions must be piloted for:

| # | Criterion | What to observe |
|---|-----------|-----------------|
| 1 | **Comprehension** | Learners understand briefs and objectives without founder coaching |
| 2 | **Task completion** | Representative tasks can be completed in intended intensity band |
| 3 | **Tool accessibility** | Required tools usable with stated modality / a11y alternatives |
| 4 | **Instruction clarity** | Instructions do not require hidden tribal knowledge |
| 5 | **Evidence feasibility** | Required Evidence can be produced safely in time box |
| 6 | **Rubric usability** | Reviewers can apply rubric consistently on pilot samples |
| 7 | **Arabic/English parity** | Arabic-first path does not lose critical meaning vs English terms |
| 8 | **Learner workload** | Workload matches LIGHT / STANDARD / DEEP / EXTENDED intent |
| 9 | **Integrity weaknesses** | AI / collusion / seed / secrets failure modes observed and mitigated |
| 10 | **Reviewer workload** | Review time fits Evidence review model expectations |
| 11 | **Technical feasibility** | Lab / sandbox / local-safe path works as blueprinted |
| 12 | **Safety** | No unsafe / offensive / live-target drift in practice |

---

## Scope rules

| Rule | Requirement |
|------|-------------|
| **Representative Missions** | Pilot a sample covering orientation, practical, assessment, Evidence prep, and Capstone path — not only quizzes |
| **Per Route** | Each P0 Route intended for publication needs its own representative pilot set |
| **CXW / SEX** | Must pilot integration / extension-specific Missions, not only source Route samples |
| **ANL reserve** | Pilot only if capacity activation is pursued |
| **Live Sky** | Pilot deferred until technical validation allows facilitated run — not claimed in 1C |
| **Document review ≠ pilot** | Scorecards and blueprint reading do **not** satisfy §45 |

## Test dimensions

| Dimension | Questions |
|-----------|-----------|
| Comprehension | Do users understand what each meter means? |
| Perceived fairness | Do outcomes feel fair under matched effort? |
| Momentum pressure | Is season pressure healthy / harmful? |
| Maturity meaning | Is Rank understood as independence, not XP? |
| Mastery understanding | Evidence-before-Mastery comprehension |
| Trust understanding | Non-public Trust intelligibility without over-disclosure |
| Appeal understanding | Do users know when/how to appeal? |
| Title interpretation | Bundle meaning vs employment promise |
| Prestige interpretation | Distinction vs immunity |
| Leaderboard impact | Opt-in / provisional / population thresholds |
| Arabic / English parity | Same meanings across languages |

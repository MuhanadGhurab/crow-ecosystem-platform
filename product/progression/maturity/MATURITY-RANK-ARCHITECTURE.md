## Purpose

Define **Maturity Ranks** as a **long-term development profile** across independence, Evidence quality habits, reflection, and sustained responsible behavior — **not** as a pure XP ladder, seasonal standing, or job-seniority title.

```text
STATUS: ARCHITECTURE RECOMMENDED

Maturity ≠ XP volume alone · ≠ Momentum · ≠ job seniority
Thresholds pending GHV.PROGRESSION.1B
No Product Code · No numeric formulas
```

## Binding definition

| Principle | Statement |
|-----------|-----------|
| **What Maturity is** | A durable Rank reflecting how the learner develops independence, judgment, documentation habits, collaboration, and self-correction over time. |
| **What Maturity is not** | Cumulative XP score, seasonal Momentum league, employment grade, Specialist Title across all fields, or Obsidian Raven Prestige. |
| **Evidence relationship** | Higher Ranks increasingly expect Evidence ownership and reflection — but Rank is not automatic from Evidence count alone. |
| **Values** | Advancement thresholds are **FORMULA PENDING** (1B). This Gate defines qualitative expectation profiles only. |

## Qualitative dimensions

Maturity evaluation considers the following dimensions. None is solely reducible to XP volume.

| Dimension | What it looks for |
|-----------|-------------------|
| **Digital independence** | Ability to navigate tools, environments, and platform workflows with decreasing hand-holding. |
| **Learning independence** | Ability to plan study, use resources, and progress without constant directed prompts. |
| **Practical execution** | Turning guidance into finished practice / Mission outcomes with growing reliability. |
| **Documentation quality** | Clarity, honesty, and usefulness of Evidence and written artifacts. |
| **Problem decomposition** | Breaking unfamiliar problems into manageable steps rather than random trial-and-error only. |
| **Responsible judgment** | Choosing safer, more ethical, and more proportionate actions under ambiguity. |
| **Collaboration** | Contributing constructively in team contexts with attributable ownership. |
| **Evidence ownership** | Treating Evidence as the learner’s accountable work product, including revisions. |
| **Self-correction** | Using feedback, remediation, and reflection to improve without external force only. |
| **Unfamiliar situations** | Transferring habits to new contexts rather than only repeating known templates. |

## Qualitative expectation profile by Rank

Profiles are **qualitative expectations**, not numeric checklists. Thresholds pending 1B.

### MAT-HATCHLING — Hatchling

Early orientation. Learner is discovering the Nest / early path, relies heavily on guidance, and is building basic digital and learning independence. Evidence, if any, is exploratory. Reflection is prompted rather than self-initiated.

### MAT-FLEDGLING — Fledgling

Emerging routine. Learner can complete guided Missions with support, begins producing simple practice artifacts, and shows first signs of following through. Documentation is basic; judgment is still heavily scaffolded.

### MAT-SCOUT — Scout

Directed exploration. Learner navigates structured Routes with less prompting, attempts problem decomposition on familiar task types, and submits Evidence that can be reviewed. Collaboration is participatory rather than leading.

### MAT-FORAGER — Forager

Resourceful practice. Learner finds and uses available resources independently, executes practical work more reliably, improves documentation after feedback, and begins self-correcting without every step being assigned.

### MAT-PATHFINDER — Pathfinder

Sustained self-direction. Learner plans learning sequences, decomposes moderately unfamiliar problems, owns Evidence revisions, and shows consistent reflection habits. Collaboration includes clear individual accountability.

### MAT-SENTINEL — Sentinel

Responsible stewardship of own standards. Learner demonstrates stable judgment under ambiguity, maintains documentation quality, supports peers constructively without displacing their ownership, and treats integrity as non-negotiable.

### MAT-SPECIALIST — Specialist

Deepened independence **within one or more demonstrated domains** — **not** a claim of mastery across all fields. Specialist Rank expects strong Evidence ownership and self-correction in the learner’s focus areas. **Specialist ≠ all fields.**

### MAT-RAVEN — Raven

Highest long-term maturity band in this ladder: broad independence, durable responsible judgment, high-quality Evidence habits, and transfer into unfamiliar situations. **Raven ≠ Obsidian Raven.** Obsidian / Prestige constructs are separate governed Prestige tracks and must not be conflated with Maturity Rank names.

## Binding rules

| ID | Rule |
|----|------|
| MAT-R1 | Maturity is **long-term**. |
| MAT-R2 | **No seasonal reset** of Maturity Rank from Momentum season close. |
| MAT-R3 | **No automatic decrease from ordinary inactivity.** Absence alone does not demote Rank. |
| MAT-R4 | Advancement **needs more than volume** (XP count, Mission count, or time-on-platform). |
| MAT-R5 | **Higher Ranks need independence** across the qualitative dimensions — not only completion speed. |
| MAT-R6 | **Rank names ≠ job seniority.** Hatchling…Raven are developmental labels, not HR grades. |
| MAT-R7 | **Specialist ≠ competence in all fields.** |
| MAT-R8 | **Raven ≠ Obsidian Raven.** Prestige is separate. |
| MAT-R9 | **Prestige is separate** from Maturity Rank advancement. |
| MAT-R10 | **Integrity findings may trigger Rank review** without deleting Flight Log history. Outcomes may include hold, remediation expectation, or governed Rank adjustment — history remains auditable. |
| MAT-R11 | **Thresholds pending GHV.PROGRESSION.1B.** No numeric Rank conditions in this document. |

## Relationship to other progression systems

| System | Relationship |
|--------|--------------|
| **Flight XP** | May supply activity signals; never sole Rank criterion. |
| **Momentum** | Seasonal pacing; does not set or reset Maturity. |
| **Mastery** | Capability demonstration; informs independence/Evidence dimensions but does not auto-assign Rank. |
| **Titles / Prestige** | Separate identity constructs; Maturity must not silently grant them. |

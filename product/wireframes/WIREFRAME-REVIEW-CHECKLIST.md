Every detailed wireframe must pass before `LOCKED AT LOW FIDELITY`:

- [ ] Purpose is clear
- [ ] Primary action is obvious
- [ ] No unnecessary competing action
- [ ] Entry and exit are defined
- [ ] State is preserved
- [ ] Locks are explained
- [ ] Payment is not confused with Skill
- [ ] Merit is visible where applicable
- [ ] Loading is defined
- [ ] Empty is defined
- [ ] Error is defined
- [ ] Offline is defined where relevant
- [ ] Mobile works
- [ ] Desktop works
- [ ] RTL works
- [ ] Accessibility is represented
- [ ] Audit requirements are represented
- [ ] Scope status is correct
- [ ] Downstream dependencies are labeled

Low-fidelity lock ≠ final UI.
